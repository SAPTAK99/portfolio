📸 ADD YOUR PROFILE PHOTO HERE!

1. Place your photo in this folder: public/images/
2. Name it: profile.jpg (or profile.png)
3. Supported formats: .jpg, .jpeg, .png, .webp

The image will automatically appear in your portfolio hero section!

If you use a different name or format, update the path in:
src/components/Hero.jsx (line 45)

Example:
- profile.jpg ✅
- profile.png ✅
- my-photo.jpg (then update Hero.jsx to use "/images/my-photo.jpg")
